# WebsiteStudio - "Старинная Коллекция" (Антикварный магазин)

Проект переработанного сайта антикварного магазина с современным дизайном и сохранением функциональности.

## Проект

Этот проект создает новый, премиальный веб-сайт антикварного магазина, ориентированный на клиентов от 40 лет и старше.

## Основные направления

**Целевая аудитория**: клиенты 40+ и старше, ценящие:
- Премиальный пользовательский опыт
- Высокое качество визуального представления
- Комплексную информацию о товаре
- Простое навигация

**Дизайн-генеральные принципы:**
- Элегантный, антикварный эстетический стиль
- Четкие кнопки и навигация
- Достаточно крупный текст
- Нет сложных анимаций
- Нет перегруженности
- Спокойные цвета, вызывающие доверие
- Реактивная верстия
- Захоронение данных
- Перспектива участия в работе

**UI/UX требования:**
- Премиальный стиль дизайна
- Удобный и понятный интерфейс
- Достаточно крупный текст
- Очевидные кнопки и элементы управления
- Нет сложных анимаций
- Без мелких элементов и перегруженности
- Визуально дорогой, спокойный и вызывающий доверие интерфейс

## Основные элементы

### Каталог товаров
- Крупные карточки товаров с фотографиями
- Данные о цене и доступности из существующего каталога
- Фильтры по категориям
- Поиск и сортировка
- Пагинация (если необходимо)

### Визуальный стиль
- Цвета: молочный, тёплый бежевый, тёмно-коричневый, приглушённый бордовый
- Основные шрифты: serif для заголовков, sans-serif для основного текста
- Естественные текстуры и спокойные фотографии
- Единообразный размер карточек, аккуратная композиция

### Функциональность
- Навигация по каталогу
- Поиск товаров
- Фильтрация и сортировка
- Переходы к товарам (детальный просмотр)
- Состояние корзины, избранное (если доступно)
- Без неработающих кнопок
- Адаптивность под компьютер, планшет и смартфон

### Анимации
- Лёгкие анимации появления
- Hover-эффекты карточек
- Плавные переходы между состояниями фильтров
- Легкое увеличение фотографий при наведении

## Техническая структура

### Файлы
- `index.html` — основная страница сайта
- `css/style.css` — основные стили
- `js/app.js` — логика приложения
- `js/catalog.json` — данные каталога (перенесены из original-site)
- `manifest.webmanifest` — PWA манифест
- `sw.js` — service worker

### Структура папок (современная)
- `assets/` — изображения (если необходимо)
- `css/` — стили проекта
- `js/` — JavaScript-файлы проекта
- `original-site/` — исходный проект (не изменяйте, используем как референс)

## Текущи статус

Проект находится в процессе разработки.

## Основная задача

1. **Создать новый дизайн каталога** — на основе референсов Attic Vintage Shop, Minente, Forma Clay Ceramics Studio и Code Object Furniture Catalog, без копирования сайтов напрямую.

2. **Использовать реальные данные** — все 203 товара из исходного каталога, включая фотографии, цены, названия, описания и категории.

3. **Сохранить функциональность** — работоспособность поиска, фильтрации, сортировки, избранного, переходов к товарам.

4. **Создать премиальный стиль** — визуально дорогой, спокойный, вызывающий доверие, ориентированный на аудиторию 40+.

5. **Обеспечить адаптивность** — корректная работа на компьютер, планшет, смартфон.

6. **Создать страницу товара** — если возможно реализовать без нарушения функциональности.

## Правила работы

- Не создавать фиктивные товары, изображения или цены
- Не изменять исходный сайт в папке `original-site`
- Использовать реальный код, функциональность и дизайн из существующего проекта как основу для работы
- Разрабатывать новый дизайн, а не копировать существующий
- Проверять работу на реальных устройствах
- Не сломать уже работоспособные функции
